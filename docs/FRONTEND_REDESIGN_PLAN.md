# CardShopDir 前端重设计方案 (Collector's Vault)

> 目标:提升停留时长与体验,让视觉贴合卡牌游戏主题。
> 红线:不改路由 / URL / metadata / canonical / sitemap / JSON-LD / H1-H2 文案 / 内链数量与锚文本。

## 1. 诊断

- 配色纯灰度,无品牌色;标题用系统衬线,像博客
- 所有模块同等权重的细边框卡片,无视觉焦点
- TCG 游戏分类(最大差异化资产)只是文字小格子
- 商店卡片缩略图小,无图为灰块 "No image"
- 详情页信息平铺,底部推荐模块弱,缺少继续浏览的动力

## 2. 设计方向

**Collector's Vault** — 灯光下的卡店柜台。风格强度:**克制的酷炫**
(深色底;holo 渐变/发光只用于 hover、focus、Top Rated、主 CTA;大面积保持干净以保证可读性与性能)。

### 色彩 (v2: 暖墨 + 箔金, 不使用蓝紫)

| Token          | Dark                                         | Light            |
| -------------- | -------------------------------------------- | ---------------- |
| background     | `#0D0B09` 暖墨                               | `#F7F1E5` 纸米   |
| card           | `#16130F`                                    | `#FFFCF5`        |
| foreground     | `#F3EBDD` 奶油白                             | `#1C1710`        |
| primary / gold | `#F0B94E` 箔金                               | `#9A5508` 深琥珀 |
| foil 渐变      | `#F7D98A → #F0B94E → #E2613B` (金→琥珀→朱红) | 同色相加深       |
| open           | `#5BD68F`                                    | `#047857`        |

各 TCG 专属色仅用于游戏标签/磁贴(单色相渐隐), 不做跨色相渐变。

### 字体 (v2)

- 标题: **Fraunces** (软衬线, 收藏/编辑感, opsz+SOFT 轴)
- 正文: **Inter**
- 微标签: **JetBrains Mono** 大写字距 ("卡牌类型行")

### 质感

- 圆角 12–16px;卡片 hover 上浮 + holo 渐变描边(纯 CSS);`prefers-reduced-motion` 降级
- 背景顶部径向光晕 + 极淡网格,不增加网络请求

## 3. 页面方案

**首页**: 大搜索栏为视觉中心 → 游戏磁贴(带游戏色)提前 → 紧凑统计条(数字滚动) → 精选店铺 → 折叠 FAQ/指南。
**目录页**: 精简 Hero + 关键数字;城市 chips 只做 CSS 折叠(全部链接保留在 DOM);sticky 筛选栏(游戏色 chips、排序、Open now);描述下移/折叠(文本仍在 HTML)。
**详情页**: 封面横幅(无图用游戏色渐变占位);吸顶操作栏(Website / Directions / Call);桌面双栏(左内容, 右 sticky 联系+地图);合并重复的 carry/games 模块;"More shops" 上移并做成横向轨道。
**商店卡片** (全站复用): 顶部大图 16:10、金色评分、绿色营业点、游戏色标签、Top Rated 金徽章、hover holo 描边。

## 4. 留存功能

- Open now 筛选 · 最近浏览 / 收藏 (localStorage, 无登录) · `/` 快捷聚焦搜索 · 骨架屏 · 详情页同游戏/同城推荐轨道 · 移动端底部固定 Call/Directions

## 5. SEO / 性能守则

1. 折叠内容必须服务端渲染在 HTML 内 (`<details>` 或 CSS 折叠), 不用 JS 条件渲染
2. `next/image`, 首屏 priority, 固定宽高防 CLS
3. 字体最多 2 族, 限定字重
4. 动效 CSS 为主, 尊重 reduced-motion
5. 每期上线后观察 Search Console (CWV、排名、点击) 3–5 天

## 9. v3 方向修正: Felt & Card Stock (牌桌 + 卡纸)

反馈: v2 仍有 AI 设计痕迹 (大圆角 / 卡片嵌套 / 明显渐变卡片 / 发光), 背景不够大胆。

- 背景: 牌桌绒布绿 `#0C3A2C` + 细噪点; 卡片面: 米色卡纸 `#F2E8CF` + 墨色 `#14110C`
- 强调: 朱红 `#C8381A` (卡纸上) / 万寿菊黄 `#F5B82E` (绿底上), 全部平涂, 无渐变无发光无毛玻璃
- 圆角 `--radius: 0.25rem`; 描边 2px 墨线; 悬停为硬阴影位移 (`.vault-card`)
- 通栏色带 `.bleed .band-paper / .band-deep`: 统计、About、各页头部与绿底对撞
- `.bg-card` 自动切换为"纸上墨"变量 (文字/次要文字/主色/边框), 卡片内无需手写反色
- 去嵌套: 详情页侧栏、时间表改为分隔线版式; 州列表改为带引导点的目录索引
- 标题字体启用 Fraunces WONK 轴 (更有个性), 游戏色改为平涂色块
- v3.1: `.band-deep` 与 `.band-felt` 同步切换为深色文字变量 (修复浅色模式下 Featured Shops 绿底黑字)
- v3.1: 新增 `components/section-title.tsx`, 目录页 / 州页 / 城市页 / 游戏页 / near-me 的区块标题统一为首页风格 (粗横线 + Mono 序号 + 大号衬线标题); 页头面包屑与标题合并进同一通栏米色色带
