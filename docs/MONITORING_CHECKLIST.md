## 每周检查清单

每周固定一天（建议周一）执行以下检查，记录数据到对应周表格。

### 检查项

- [ ] **GSC — 索引状态**
  - GSC → 页面索引 → 查看已索引页面数
  - GSC → 网页 → 查看 "已发现 - 尚未编入索引" / "已抓取 - 尚未编入索引" 数量
  - GSC → sitemap → 查看 sitemap 状态和已发现 URL 数

- [ ] **GSC — 搜索表现**
  - GSC → 搜索结果 → 过去 7 天 → 记录点击数、展示次数、平均排名、CTR
  - 查看出现的关键词列表，记录新出现的关键词

- [ ] **Bing — 索引状态**
  - Bing Webmaster Tools → SEO 报告 → 已索引页面数
  - Bing → Sitemaps → sitemap 提交状态

- [ ] **Umami — 流量数据**
  - 访问量（PV / UV）
  - 流量来源（直接 / 搜索 / 外链 / 社交）
  - 热门页面 Top 10
  - 搜索关键词（如果有搜索流量）

- [ ] **技术健康检查**
  - `pm2 status` — 应用是否正常运行
  - `curl -sS -o /dev/null -w "%{http_code}" https://cardshopdir.com` — 首页 200
  - `curl -sS -o /dev/null -w "%{http_code}" https://cardshopdir.com/sitemap.xml` — sitemap 可访问
  - GSC → 核心网页指标 → LCP / INP / CLS 是否绿色
  - 检查是否有 GSC 手动操作处罚通知

- [ ] **异常检查**
  - GSC 是否有错误通知（服务器错误 5xx、重定向错误等）
  - 是否有页面从索引中被移除
  - Umami 是否有异常流量（爬虫轰炸等）

## No-Go 时的排查清单

如果索引不增长或流量为零，按以下顺序排查：

1. **robots.txt 是否屏蔽了爬虫**
   - `curl https://cardshopdir.com/robots.txt`
   - 确认没有 `Disallow: /`

2. **页面是否误设 noindex**
   - `curl -sS https://cardshopdir.com/directory/ca | grep -i noindex`
   - 应该只有 search 页和 admin 页是 noindex

3. **sitemap 是否可访问**
   - `curl -sS https://cardshopdir.com/sitemap.xml | head -20`
   - 确认 XML 格式正确

4. **页面加载速度**
   - PageSpeed Insights 检查
   - LCP > 4s 会严重影响索引

5. **服务器响应时间**
   - `curl -sS -o /dev/null -w "%{time_total}s\n" https://cardshopdir.com`
   - 应 < 1s

6. **是否有重复内容问题**
   - GSC → 网页 → 检查 "重复网页 - 用户未指定规范"

7. **域名是否被 sandbox**
   - 新域名通常有 2-4 周 sandbox 期
   - 如果 8 周后仍无索引，可能需要增加外链
