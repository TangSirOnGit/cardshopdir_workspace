## Design Context

### Users
TCG players, collectors, and hobbyists looking for card shops near them. They want to find shops by location, game type, and services offered. They value accurate info (hours, location, games stocked) over marketing.

### Brand Personality
**Clean. Sharp. Trustworthy.** Like a well-organized reference guide. Confident in its utility. Never tries too hard.

### Aesthetic Direction
- **Tone**: Clean monochrome with subtle warmth. Information-first design.
- **References**: Linear.app (precision), Google Maps (utility), Yelp (directory UX)
- **Anti-references**: Cluttered directories, ad-heavy layouts, generic templates
- **Theme**: Light mode. Neutral palette with selective accent for ratings/CTAs.
- **Typography**: Inter + Instrument Serif
- **Cards**: Shop cards with key info (name, rating, games, distance). Dense but scannable.

### Design Principles
1. **Information density** — Show key shop info (rating, games, hours, distance) at a glance.
2. **Geographic clarity** — Location hierarchy (state > city > shop) always visible via breadcrumbs.
3. **Scannable lists** — Shop cards should be skimmable. Rating and games are primary signals.
4. **Map integration** — Location context is core, not an afterthought.
5. **Earned complexity** — Start with clean lists. Add filters, maps, and sorting only where they help.
